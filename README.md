# EZ-Bikes — متجر محلي بالعربي

نسخة تجريبية محلية (RTL) لمتجر عجل كهربائي: شراء، تحويل عجلة قديمة، برنامج إحالة، حساب عميل، ودعم — بلوحة إدارة كاملة.

- **TURK 90** — ٢٤٬٠٠٠ جنيه (كاوتش رفيع)
- **HULK 101** — ٣٥٬٠٠٠ جنيه (كاوتش عريض)

الأسعار والمخزون بيتغيروا من لوحة الإدارة. الصور المعروضة تصورات للمنتج، والموقع مبيعلنش سرعة أو مدى أو ضمان أو مواعيد توصيل.

## التشغيل

المتطلبات: **Node.js 24 أو أحدث** (بيستخدم `node:sqlite` المدمج، مفيش حزم خارجية).

```powershell
cd K:\EZ-Bike\website\opencode\1
npm start
```

أو دوس على `Start EZ-Bikes.cmd`. العنوان الافتراضي: <http://127.0.0.1:3186>.

لتغيير البورت:

```powershell
$env:PORT=3190; node server.mjs
```

قاعدة البيانات بتتزرع أول مرة في `data/store.sqlite` بموديلين ومخزون ٥ لكل واحد. امسح ملفات `data/store.sqlite*` (والسيرفر واقف) لو عايز تبدأ من جديد.

## إنشاء أول حساب إدارة

مفيش حساب إدارة افتراضي. أنشئ واحد بعد ما السيرفر يبدأ أول مرة:

```powershell
cd K:\EZ-Bike\website\opencode\1
$env:EZ_ADMIN_PASSWORD='كلمة-مرور-قوية-هنا'
node server.mjs admin you@example.com
```

الدخول من `/login`، وبعدها هتفتح لوحة الإدارة على `/admin`.

> لو عايز تستخدم قاعدة بيانات تانية: `$env:EZ_DB='C:\path\store.sqlite'` قبل أي أمر.

## الاختبارات

```powershell
npm test
```

١٦ اختبار تكاملي على قاعدة بيانات مؤقتة (مش بيلمسوا `data/store.sqlite`): شراء، إحالة، عمولة، سحب، رفض، إرجاع، خصوصية التحويل، دعم، تتبع زائر، استبدال، منع الإحالة الذاتية، رفض POST من مصدر تاني، حماية صفحة الإدارة، وتحديث السعر.

## الدورة التشغيلية

**الطلب:** `قيد المراجعة → تم التأكيد → تم التحصيل → تم التسليم → مكتمل`، مع إمكانية الإلغاء قبل التسليم والإرجاع بعد التسليم. المخزون بيتخصم أول ما الطلب يتسجل، والعمولة بتتسجل «بانتظار الاعتماد» لما الطلب يوصل «مكتمل».

**الإحالة:** ١٬٠٠٠ جنيه لكل شراء مؤهل ومكتمل. الكود المكتوب وقت الطلب له الأولوية، وآخر لينك إحالة بيفضل صالح ٣٠ يوم. الإلغاء أو الإرجاع بيعكس العمولة حتى لو كانت معتمدة. صاحب الإحالة بيشوف رقم الطلب وحالته وقيمة العمولة فقط — مفيش اسم أو تليفون أو عنوان أو بريد للمشتري.

**السحب والاستبدال:** العمولة لازم تعتمدها الإدارة الأول. بعد كده العميل يقدر يطلب سحب نقدي، أو يستبدل رصيده بعجلة عند وصوله لسعر الموديل المختار (٢٤٬٠٠٠ أو ٣٥٬٠٠٠). المبلغ بيتحجز وقت الطلب ويرجع لو اترفض. الاستبدال الموافق عليه بيخصم مخزون الموديل.

**التحويل:** عميل يبعت بيانات وصور عجلته، الإدارة تراجع وتحدد عرض سعر وموعد. التكلفة الداخلية (٨٬٠٠٠–١٠٬٠٠٠ جنيه) مش بتظهر للعميل، والتحويل مش بيكسب عمولة إحالة.

**الطلبات اليدوية:** من `/admin/manual` تقدر تسجل طلب واتساب لحساب موجود أو لزائر. طلب الزائر بيتتبع برقم الطلب والتليفون من `/track`. السعر والتكلفة الداخلية (١٥٬٠٠٠ جنيه للموديل) بيظهروا للإدارة فقط.

**لوحة الإدارة:** تغيير الأسعار والمخزون، نقل حالة الطلبات، اعتماد/عكس العمولات، قرارات السحب والاستبدال، عروض التحويل، الرد على الدعم، وقياس «المتبقي التقديري» بعد تكلفة العجل والعمولات — **قبل أي مصاريف تانية وليس صافي ربح**.

## الخصوصية والأمان

- كلمات المرور متخزنة بـ scrypt مع salt، والجلسات على السيرفر بكوكي `HttpOnly` و`SameSite=Lax`.
- كل التحقق المهم (السعر، الحالة، الرصيد، الملكية، صلاحية الإدارة) بيحصل على السيرفر.
- في حماية من CSRF عبر فحص `Origin`، وحدود محاولات لتسجيل الدخول والتتبع، ورفع صور بفحص النوع والحجم.
- رؤوس أمان أساسية، والصور بتتخدم من مسار محمي بالملكية.
- مفيش دفع أونلاين: التحصيل والصرف والاستبدال بمراجعة يدوية.

## قبل الاستخدام الحقيقي

- غيّر أي بيانات تجريبية، وأنشئ حساب إدارة بكلمة مرور قوية، وخزّن نسخة احتياطية من `data/`.
- شغّل خلف HTTPS أو reverse proxy، وحدد `EZ_PUBLIC_URL` بالعنوان النهائي.
- راجع سياسات الاستبدال والإرجاع والخصوصية والضمان مع جهة قانونية، واكتب مواصفات المنتج الحقيقية بدل التصورات.
- راجع حدود المحاولات والرفع، واختبر الدفع/التحصيل والتوصيل يدويًا قبل أي إطلاق.
- النسخة دي محلية: مفيش بريد أو SMS أو بوابة دفع أو تعدد سيرفرات.
